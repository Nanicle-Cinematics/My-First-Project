# Legal And Support Readiness

Public pages now exist at:

- `/terms`
- `/privacy`
- `/support`

These are operational drafts. They must be reviewed before broad paid SaaS launch.

## Before Public Sale

- Replace draft terms with counsel-approved Terms of Service.
- Replace draft privacy text with counsel-approved Privacy Policy.
- Add refund, cancellation and billing terms.
- Add data processing terms for churches that request them.
- Confirm retention requirements for finance and member records.
- Publish support hours and response targets.

## Support Intake

Every support request should include:

- Church name.
- User role.
- Page URL.
- Screenshot if possible.
- Expected result.
- Actual result.
- Whether it affects live finance or member data.

## Severity Guide

- Critical: app unavailable, login lockout, backup failure, finance posting corruption, data missing.
- High: SMS/email failure, imports blocked, receipt/voucher print blocked.
- Normal: report formatting, UI confusion, training question.
- Low: feature request or copy change.
