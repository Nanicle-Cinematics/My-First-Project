Reduced-motion
To verify your OS / browser respects motion preferences, enable Reduce motion in your system settings and refresh this page. All transitions should collapse to near-instant. Test in DevTools → Rendering → Emulate CSS media → prefers-reduced-motion: reduce.

Accessibility #a11y

The gallery is a build-time tool only — but it follows the same rules every shipped page must.

  • All interactive elements reachable from the keyboard alone.
  • Focus ring is always visible. Never outline: none without replacement.
  • Contrast meets WCAG AA (4.5:1 body, 3:1 ≥18pt). Test with WAVE / axe.
  • One h1 per page; never skip heading levels.
  • Every form field has a <label for>; errors linked via aria-describedby.
  • Decorative icons get aria-hidden="true"; meaningful icons get an accessible name.
  • Charts include <title> + screen-reader data-table fallback.
  • Motion respects prefers-reduced-motion.
  • Touch targets ≥ 44×44px on coarse pointer.
